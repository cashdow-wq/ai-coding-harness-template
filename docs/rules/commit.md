# Commit Rule

Do not commit unless the user explicitly asks.

## Commit Message Format

Use:

`type(scope): summary`

Examples:

- `Feat(auth): add login session check`
- `Fix(menu): handle refresh with dynamic menu`
- `Refactor(api): simplify response mapping`
- `Docs(workflow): add agent workflow rules`

## Rules

- One commit should have one purpose.
- Do not mix formatting-only changes with feature changes.
- Mention verification result before suggesting commit.
- Commit title, message must be written Korean.
