# Worklog Rule

Use worklog for meaningful changes, not every tiny edit.

## Location

Write logs under:

`docs/worklog/YYYY-MM.md`

## Format

### YYYY-MM-DD / branch-name

- Goal:
- Changed:
- Verified:
- Remaining:
- Notes:

## Rules

- Keep it short.
- Mention failed or skipped verification.
- Mention risky decisions.
